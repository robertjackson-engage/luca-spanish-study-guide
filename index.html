-AR VERBS

subjectendingestudiar
yo-oestudio
tú-asestudias
él / ella / usted-aestudia
nosotros (… y yo)-amosestudiamos
vosotros-áisestudiáis
ellos / ellas / ustedes (X y Y)-anestudian
“Héctor y yo” = nosotros → -amos. “Tomás y Patricia” = ellos → -an. Usted uses the él/ella form → -a.

ESTAR

subjectestar
yoestoy
túestás
él / ella / ustedestá
nosotrosestamos
vosotrosestáis
ellos / ellas / ustedesestán
Accents on estás, está, están. Location sentences always need estar: “Las mochilas están detrás de las sillas.”

GUSTAR

me gusta = I like · te gusta = you like

gusta + one thing or a verb (dibujar, la literatura)

gustan + plural things (las matemáticas, los libros)

Matching trick: statement ends in -o (Tomo…) → answer uses me. Ends in -as (Trabajas…) → answer uses te.
